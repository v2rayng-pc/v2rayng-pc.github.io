03 · Установка

Настройка занимает пять минут

Никаких драйверов и сложных конфигов: скачайте v2rayNG на компьютер, импортируйте профиль вашего провайдера — и туннель готов.

  1. Скачайте portable-сборку

    Выберите архив x64 или ARM64 из таблицы выше и сохраните его на компьютер. Перед запуском сверьте SHA-256 с суммой из релиза.

  2. Распакуйте архив

    Установка не требуется: распакуйте скачанный .zip в любую папку (например, C:\v2rayNG) и запустите v2rayng.exe. Права администратора не нужны.

  3. Импортируйте профиль сервера

    Вставьте ссылку-подписку из буфера обмена (Ctrl+V в окне программы), отсканируйте QR-код или добавьте сервер вручную.

  4. Включите туннель

    Выберите сервер из списка и нажмите «Подключить». При необходимости включите системный прокси в настройках, чтобы трафик всех приложений шел через туннель.

  1. Скачайте пакет для вашего дистрибутива

    Для Debian/Ubuntu подходит .deb, для остальных — универсальный .AppImage.

  2. Установите пакет
    sudo dpkg -i v2rayng_1.9.29_amd64.deb

    Либо для AppImage — дайте файлу права на запуск и запустите:

    chmod +x v2rayng.AppImage && ./v2rayng.AppImage
  3. Импортируйте профиль

    Добавьте сервер по ссылке-подписке или из буфера обмена — так же, как в Windows-версии.

  4. Запустите туннель

    Выберите сервер и нажмите «Подключить». Проверить работу можно, открыв любой сайт в браузере.
